Odisha OCF learning outcomes, by stage

Download the PDF guidelines for the new Odisha Curriculum Framework (OCF), aligned with NIPUN Bharat and FLN targets. Follow the educational milestones across Maulika Stara (Foundational), Prastuti Stara (Preparatory) and Madhya Stara (Middle).

Please use these together with the latest circulars from your department.

Which stage covers which classes?

Maulika Stara: Shishuvatika to Class 2. Prastuti Stara: Class 3 to 5. Madhya Stara: Class 6 to 8.

What is Maulika Stara?

The foundational stage. It includes the framework and Foundational Literacy and Numeracy (FLN) outcomes.
